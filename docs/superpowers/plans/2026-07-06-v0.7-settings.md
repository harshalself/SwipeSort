# SwipeSort v0.7 — User Settings Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Prerequisite:** v0.6 tagged. Filters work end-to-end.

**Goal:** Introduce a user-facing Settings screen so cross-cutting behaviors (theme, gesture direction, autoplay, haptics, commit-review shortcut, reviewed-marker reset) are configurable without a rebuild. Distinct from the hidden Debug menu added in v0.2 — the Debug menu is developer-only (`DryRunMode`); Settings is the user-visible preferences surface.

**Architecture:** One `AppSettings` observable type backed by `UserDefaults`, injected as an `@Environment` value so any view can read live values. A single `SettingsView` presented modally from a gear button in `LandingView`. Existing feature code (swipe direction, haptics, autoplay decision) reads from `AppSettings` instead of hardcoded constants.

**Tech Stack:** Same. Adds `@Observable` `AppSettings` class, SwiftUI `.preferredColorScheme` binding, `UIImpactFeedbackGenerator` gated by the haptics flag.

**Signatures after this version:**
- `AppSettings` — top-level `@Observable` class, singleton per process, `UserDefaults` persisted.
- `SwipeStackView` reads `@Environment(AppSettings.self)` — no new init argument.
- `LandingView` gains a gear icon in the top-right toolbar opening `SettingsView`.

## Global Constraints

- All prior constraints apply.
- **Settings live in UserDefaults, not SwiftData.** They're small, plural, and don't need querying. SwiftData stays reserved for the reviewed-asset store.
- **Every setting has a hardcoded safe default** — a fresh install must be usable without opening Settings first.
- **Theme switch is instant** — no restart. Applied via `.preferredColorScheme` on the root scene.
- **Swipe direction change takes effect on the next swipe**, never mid-gesture. No mid-flight remapping.
- **Reset-reviewed-markers is destructive** — always requires a confirmation alert. Distinct from `DryRunMode` (which gates *photo* deletes, not app-local persistence).

## Research References

- `docs/RESEARCH.md` §3 competitor gaps — the "swipe direction remapping" ask is real; several competitors force a direction users disagree with.
- SwiftUI `.preferredColorScheme` — a `View` modifier reading an optional `ColorScheme`; nil = follow system.
- `UIImpactFeedbackGenerator.impactOccurred()` — cheap, but calling it thousands of times during a fast swipe session on a device without a Taptic engine is a battery smell. Gate on the toggle.

Create `SwipeSort/Core/AppSettings.swift`:

```swift
import Foundation
import Observation

enum ThemeMode: String, CaseIterable, Codable, Sendable {
    case system, light, dark
}

enum SwipeDirection: String, CaseIterable, Codable, Sendable {
    case right, left
}

/// User-facing preferences persisted in UserDefaults. Distinct from `DryRunMode`
/// (a developer-only kill-switch). Injected as `@Environment(AppSettings.self)`.
@Observable
final class AppSettings {
    // MARK: Keys
    private enum Key {
        static let themeMode = "settings.themeMode"
        static let deleteDirection = "settings.deleteSwipeDirection"
        static let autoplayVideos = "settings.autoplayVideos"
        static let autoplayMaxSeconds = "settings.autoplayMaxSeconds"
        static let hapticsEnabled = "settings.hapticsEnabled"
        static let skipCommitReview = "settings.skipCommitReview"
    }

    // MARK: Storage
    private let defaults: UserDefaults
    init(defaults: UserDefaults = .standard) {
        self.defaults = defaults
    }

    // MARK: Properties

    var themeMode: ThemeMode {
        get {
            guard let raw = defaults.string(forKey: Key.themeMode),
                  let m = ThemeMode(rawValue: raw) else { return .system }
            return m
        }
        set { defaults.set(newValue.rawValue, forKey: Key.themeMode) }
    }

    var deleteSwipeDirection: SwipeDirection {
        get {
            guard let raw = defaults.string(forKey: Key.deleteDirection),
                  let d = SwipeDirection(rawValue: raw) else { return .right }
            return d
        }
        set { defaults.set(newValue.rawValue, forKey: Key.deleteDirection) }
    }

    var autoplayVideos: Bool {
        get {
            guard let v = defaults.object(forKey: Key.autoplayVideos) as? Bool else { return true }
            return v
        }
        set { defaults.set(newValue, forKey: Key.autoplayVideos) }
    }

    /// Videos longer than this show a tap-to-play thumbnail instead of autoplaying.
    /// Clamped to [0, 600] — a 10-minute upper bound is generous for any real photo library.
    var autoplayMaxSeconds: Double {
        get {
            let v = defaults.object(forKey: Key.autoplayMaxSeconds) as? Double
            return v ?? 30
        }
        set {
            let clamped = min(max(newValue, 0), 600)
            defaults.set(clamped, forKey: Key.autoplayMaxSeconds)
        }
    }

    var hapticsEnabled: Bool {
        get {
            guard let v = defaults.object(forKey: Key.hapticsEnabled) as? Bool else { return true }
            return v
        }
        set { defaults.set(newValue, forKey: Key.hapticsEnabled) }
    }

    /// When true, `commitDecisions()` fires the system delete prompt without showing
    /// `ReviewCommitView` first. Default false — safer path.
    var skipCommitReview: Bool {
        get {
            guard let v = defaults.object(forKey: Key.skipCommitReview) as? Bool else { return false }
            return v
        }
        set { defaults.set(newValue, forKey: Key.skipCommitReview) }
    }
}
```

import SwiftUI

struct SettingsView: View {
    @Environment(AppSettings.self) private var settings
    @Environment(\.dismiss) private var dismiss

    var body: some View {
        @Bindable var s = settings

        NavigationStack {
            Form {
                Section("Appearance") {
                    Picker("Theme", selection: $s.themeMode) {
                        ForEach(ThemeMode.allCases, id: \.self) { m in
                            Text(m.displayName).tag(m)
                        }
                    }
                }

                Section("Gestures") {
                    Picker("Delete swipe direction", selection: $s.deleteSwipeDirection) {
                        Text("Right").tag(SwipeDirection.right)
                        Text("Left").tag(SwipeDirection.left)
                    }
                    Toggle("Haptic feedback", isOn: $s.hapticsEnabled)
                }

                Section("Video Playback") {
                    Toggle("Autoplay videos", isOn: $s.autoplayVideos)
                    if s.autoplayVideos {
                        VStack(alignment: .leading, spacing: 4) {
                            Text("Autoplay only videos under \(Int(s.autoplayMaxSeconds))s")
                                .font(.footnote)
                                .foregroundStyle(.secondary)
                            Slider(value: $s.autoplayMaxSeconds, in: 0...120, step: 5)
                        }
                    }
                }

                Section("Deletion") {
                    Toggle("Skip review-before-commit sheet", isOn: $s.skipCommitReview)
                } footer: {
                    if s.skipCommitReview {
                        Text("Swipes fire the system delete prompt without showing the review list. Faster but less reversible.")
                            .foregroundStyle(.orange)
                    } else {
                        Text("Swipes are queued; tap Commit to see the list and confirm.")
                    }
                }

                Section("Library") {
                    NavigationLink("Reset reviewed markers") {
                        ResetReviewedConfirmView()
                    }
                }

                Section {
                    NavigationLink("About SwipeSort") { AboutView() }
                }
            }
            .navigationTitle("Settings")
            .navigationBarTitleDisplayMode(.inline)
            .toolbar {
                ToolbarItem(placement: .confirmationAction) {
                    Button("Done") { dismiss() }
                }
            }
        }
    }
}

private extension ThemeMode {
    var displayName: String {
        switch self {
        case .system: return "System"
        case .light: return "Light"
        case .dark: return "Dark"
        }
    }
}

- [ ] **Step 2: Add a swipe-side abstraction in `SwipeSessionModel`**

Replace direction-specific method names with a single `swipe(_:using:)`:

```swift
enum SwipeSide { case left, right }

extension SwipeSessionModel {
    /// Resolves the semantic action (delete vs keep) from the physical swipe side
    /// via the user's configured direction. Prefer this over `swipeDelete()` /
    /// `swipeKeep()` in view code — those two remain as internal helpers.
    func swipe(_ side: SwipeSide, using settings: AppSettings) async {
        let isDelete = (side == settings.deleteSwipeDirection.asSide)
        if isDelete { await swipeDelete() } else { await swipeKeep() }
    }
}

private extension SwipeDirection {
    var asSide: SwipeSide { self == .right ? .right : .left }
}
```
