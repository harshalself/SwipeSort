# SwipeSort v0.1 — Skeleton Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Prove the PhotoKit + SwiftUI foundation works — authorize the library, fetch assets lazily, render a single swipe card backed by `PHCachingImageManager`, capture keep/delete decisions in an in-memory queue. **No actual deletion happens in v0.1.**

**Architecture:** Model-View-Observable with `@Observable` state. Every PhotoKit interaction goes through a `PhotoLibraryProviding` protocol so tests can substitute a `MockPhotoLibrary`. SwiftData is scaffolded but only holds a schema — no persistence logic yet. All destructive paths are guarded by `DryRunMode` (defaults to true in v0.1).

**Tech Stack:** Xcode 15+, Swift 5.9+, iOS 17.0+ deployment target, SwiftUI, PhotoKit, SwiftData, Swift Testing.

## Global Constraints

- iOS 17.0+ deployment target.
- Swift concurrency (`async`/`await`); avoid completion-handler wrappers in new code.
- Full `.readWrite` PhotoKit access (no limited-access branch in v0.1).
- Every PhotoKit call goes through the `PhotoLibraryProviding` protocol.
- Every destructive operation gated on `DryRunMode.isEnabled` — a UserDefaults-backed flag, default true. v0.1 has no UI to change it; v0.2 adds a debug-menu toggle.
- Swipe direction is hardcoded in v0.1: **right = delete, left = keep** (per vision doc). v0.7 makes this user-configurable via `AppSettings.deleteSwipeDirection`.
- Haptics and video autoplay behavior are similarly hardcoded in v0.1–v0.6 (haptics on, autoplay for videos ≤30s). v0.7 routes both through `AppSettings`.
- Tests use Swift Testing (`import Testing`), not XCTest.
- Never convert `PHFetchResult<PHAsset>` to `[PHAsset]` — lazy cursor semantics.
- `PHCachingImageManager` `targetSize` in **pixels** (`points × UIScreen.main.scale`).
- Frequent commits — one per task minimum.
- Prompt: `NSPhotoLibraryUsageDescription = "SwipeSort needs access to your photo library to help you sort and clean up media."`

```swift
import Foundation

/// Global kill-switch for destructive PhotoKit operations, persisted in UserDefaults
/// so the setting survives app restarts. Any code path that would delete, move, or
/// otherwise mutate the user's photo library must gate on `DryRunMode.isEnabled` and
/// log via `os.Logger` when true instead of executing.
///
/// Default is `true` (safe). A debug-menu UI toggle in v0.2 flips this at runtime.
enum DryRunMode {
    static let defaultsKey = "swipesort.dryRun"

    /// True unless UserDefaults explicitly sets the key to `false`. Missing = safe.
    static func isEnabled(defaults: UserDefaults = .standard) -> Bool {
        // `object(forKey:)` distinguishes "unset" (nil → true) from "set to false".
        guard let raw = defaults.object(forKey: defaultsKey) as? Bool else { return true }
        return raw
    }

    static func setEnabled(_ value: Bool, defaults: UserDefaults = .standard) {
        defaults.set(value, forKey: defaultsKey)
    }

    /// Convenience accessor for call sites that don't need to inject defaults.
    static var isEnabled: Bool { isEnabled() }
}
```

```swift
import Foundation
import UIKit

/// A stable handle for a `PHAsset` — its `localIdentifier`, wrapped so callers
/// can't accidentally pass a raw string.
struct AssetIdentifier: Hashable, Sendable {
    let rawValue: String
    init(_ rawValue: String) { self.rawValue = rawValue }
}

/// A rendered thumbnail plus enough metadata to know if a higher-quality
/// version is still coming (progressive delivery via `.opportunistic`).
struct AssetThumbnail: Sendable {
    let identifier: AssetIdentifier
    let image: UIImage
    let isDegraded: Bool
}

/// Mirrors `PHAuthorizationStatus` but decoupled so tests don't touch PhotoKit.
enum PhotoLibraryAuthorization: Sendable {
    case notDetermined
    case denied
    case restricted
    case limited
    case authorized
}

/// Every read of the user's photo library goes through this protocol so
/// tests substitute an in-memory `MockPhotoLibrary`. v0.1 exposes only the
/// read operations needed to render a swipe stack.
protocol PhotoLibraryProviding: Sendable {
    func currentAuthorization() async -> PhotoLibraryAuthorization
    func requestAuthorization() async -> PhotoLibraryAuthorization
    func assetCount() async -> Int
    func assetIdentifier(at index: Int) async -> AssetIdentifier?
    func thumbnail(for identifier: AssetIdentifier, targetSize: CGSize) async -> AssetThumbnail?
}
```

Create `SwipeSort/Core/PhotoKitLibrary.swift`:

```swift
import Foundation
import Photos
import UIKit

/// Real PhotoKit-backed implementation of `PhotoLibraryProviding`.
///
/// Design notes (see docs/RESEARCH.md §4.1, §4.2):
/// - Holds `PHFetchResult<PHAsset>` as a lazy cursor. **Never** materialize
///   it to an array.
/// - Uses one shared `PHCachingImageManager`. Callers do not manage the
///   caching window themselves in v0.1; we just request thumbnails as
///   swipes happen. Windowed pre-caching arrives in Task 9 / v0.2.
/// - Every `requestImage` uses pixel-scaled `targetSize`,
///   `.aspectFill`, `.opportunistic` delivery, and
///   `isNetworkAccessAllowed = true` so iCloud assets download.
final class PhotoKitLibrary: PhotoLibraryProviding, @unchecked Sendable {

    private let imageManager = PHCachingImageManager()
    private var fetchResult: PHFetchResult<PHAsset>?

    func currentAuthorization() async -> PhotoLibraryAuthorization {
        map(PHPhotoLibrary.authorizationStatus(for: .readWrite))
    }

    func requestAuthorization() async -> PhotoLibraryAuthorization {
        await withCheckedContinuation { cont in
            PHPhotoLibrary.requestAuthorization(for: .readWrite) { status in
                cont.resume(returning: self.map(status))
            }
        }
    }

    func assetCount() async -> Int {
        await ensureFetchResult().count
    }

    func assetIdentifier(at index: Int) async -> AssetIdentifier? {
        let result = await ensureFetchResult()
        guard (0..<result.count).contains(index) else { return nil }
        return AssetIdentifier(result.object(at: index).localIdentifier)
    }

    func thumbnail(for identifier: AssetIdentifier, targetSize: CGSize) async -> AssetThumbnail? {
        let result = await ensureFetchResult()
        // Linear scan is fine for v0.1 (small stacks). v0.2+ will pass indices directly.
        var found: PHAsset?
        result.enumerateObjects { asset, _, stop in
            if asset.localIdentifier == identifier.rawValue {
                found = asset
                stop.pointee = true
            }
        }
        guard let asset = found else { return nil }

        let options = PHImageRequestOptions()
        options.deliveryMode = .opportunistic
        options.resizeMode = .fast
        options.isNetworkAccessAllowed = true
        options.isSynchronous = false

        return await withCheckedContinuation { cont in
            var haveResumed = false
            imageManager.requestImage(
                for: asset,
                targetSize: targetSize,
                contentMode: .aspectFill,
                options: options
            ) { image, info in
                // Progressive delivery calls this callback multiple times.
                // Resume on the first non-nil image; ignore subsequent ones
                // to avoid double-resume crash.
                guard !haveResumed, let image else { return }
                let isDegraded = (info?[PHImageResultIsDegradedKey] as? Bool) ?? false
                haveResumed = true
                cont.resume(returning: AssetThumbnail(
                    identifier: identifier,
                    image: image,
                    isDegraded: isDegraded
                ))
            }
        }
    }

    // MARK: - Private

    private func ensureFetchResult() async -> PHFetchResult<PHAsset> {
        if let existing = fetchResult { return existing }
        let options = PHFetchOptions()
        options.sortDescriptors = [NSSortDescriptor(key: "creationDate", ascending: false)]
        // Include Live Photos + images + videos. Bursts handled properly in v0.4+.
        let result = PHAsset.fetchAssets(with: options)
        fetchResult = result
        return result
    }

    private func map(_ status: PHAuthorizationStatus) -> PhotoLibraryAuthorization {
        switch status {
        case .notDetermined: return .notDetermined
        case .restricted:   return .restricted
        case .denied:       return .denied
        case .authorized:   return .authorized
        case .limited:      return .limited
        @unknown default:   return .denied
        }
    }
}
```

```swift
import Observation

/// A single keep-or-delete decision for one asset. v0.1 has only two kinds;
/// v0.4 adds `.moveToAlbum(...)`.
enum SwipeDecision: Sendable, Equatable {
    case keep(AssetIdentifier)
    case delete(AssetIdentifier)

    var identifier: AssetIdentifier {
        switch self {
        case .keep(let id), .delete(let id): return id
        }
    }
}

/// In-memory queue of the current session's decisions. Observable so SwiftUI
/// counters re-render on push/pop. In v0.1 the queue lives only for the
/// lifetime of the app process — persistence arrives in v0.3.
@Observable
final class DecisionQueue {

    private(set) var decisions: [SwipeDecision] = []

    var deleteCount: Int {
        decisions.reduce(0) { $0 + (isDelete($1) ? 1 : 0) }
    }

    var keepCount: Int {
        decisions.reduce(0) { $0 + (isDelete($1) ? 0 : 1) }
    }

    func record(_ decision: SwipeDecision) {
        decisions.append(decision)
    }

    /// Removes and returns the most recent decision. Returns `nil` if empty.
    @discardableResult
    func undoLast() -> SwipeDecision? {
        decisions.popLast()
    }

    private func isDelete(_ decision: SwipeDecision) -> Bool {
        if case .delete = decision { return true }
        return false
    }
}
```

```swift
import Foundation
import Observation
import UIKit

/// Drives the swipe UI. Owns the fetch cursor position, the current
/// thumbnail, and the decision queue. All PhotoKit access is proxied
/// through the injected `PhotoLibraryProviding`.
@Observable
@MainActor
final class SwipeSessionModel {

    enum Phase: Equatable {
        case idle
        case requestingAuthorization
        case denied
        case loading
        case ready
        case finished
    }

    private(set) var phase: Phase = .idle
    private(set) var currentThumbnail: AssetThumbnail?
    private(set) var currentIndex: Int = 0
    private(set) var totalCount: Int = 0

    let queue = DecisionQueue()

    private let library: PhotoLibraryProviding
    private let targetSize: CGSize

    init(library: PhotoLibraryProviding, targetSize: CGSize) {
        self.library = library
        self.targetSize = targetSize
    }

    func start() async {
        let auth = await library.currentAuthorization()
        let resolvedAuth: PhotoLibraryAuthorization
        if auth == .notDetermined {
            phase = .requestingAuthorization
            resolvedAuth = await library.requestAuthorization()
        } else {
            resolvedAuth = auth
        }

        switch resolvedAuth {
        case .authorized, .limited:
            await loadInitial()
        case .denied, .restricted, .notDetermined:
            phase = .denied
        }
    }

    func swipeKeep() async {
        guard let thumb = currentThumbnail else { return }
        queue.record(.keep(thumb.identifier))
        await advance()
    }

    func swipeDelete() async {
        guard let thumb = currentThumbnail else { return }
        queue.record(.delete(thumb.identifier))
        await advance()
    }

    func undo() async {
        guard queue.undoLast() != nil else { return }
        currentIndex = max(0, currentIndex - 1)
        phase = .ready
        await loadCurrent()
    }

    // MARK: - Private

    private func loadInitial() async {
        phase = .loading
        totalCount = await library.assetCount()
        currentIndex = 0

        if totalCount == 0 {
            phase = .finished
            currentThumbnail = nil
            return
        }

        await loadCurrent()
        phase = .ready
    }

    private func advance() async {
        currentIndex += 1
        if currentIndex >= totalCount {
            phase = .finished
            currentThumbnail = nil
            return
        }
        await loadCurrent()
    }

    private func loadCurrent() async {
        guard let id = await library.assetIdentifier(at: currentIndex) else {
            currentThumbnail = nil
            return
        }
        currentThumbnail = await library.thumbnail(for: id, targetSize: targetSize)
    }
}
```

```swift
import SwiftUI

/// Top-level swipe UI. Owns a `SwipeSessionModel` and translates drag
/// gestures into keep/delete decisions. Right = keep, left = delete.
/// v0.1 uses a simple `DragGesture` with a translation threshold; card
/// stacking and neighbor preloading arrive in v0.5.
struct SwipeStackView: View {

    @State private var model: SwipeSessionModel
    @State private var dragOffset: CGSize = .zero

    private let horizontalThreshold: CGFloat = 100

    init(library: PhotoLibraryProviding) {
        // targetSize is a first-pass approximation. In v0.5 we'll compute
        // this from the actual card frame via GeometryReader.
        let scale = UIScreen.main.scale
        let target = CGSize(width: 400 * scale, height: 600 * scale)
        _model = State(initialValue: SwipeSessionModel(library: library, targetSize: target))
    }

    var body: some View {
        VStack(spacing: 16) {
            header

            ZStack {
                switch model.phase {
                case .idle, .loading, .requestingAuthorization:
                    ProgressView("Loading library…")

                case .denied:
                    permissionDenied

                case .ready:
                    SwipeCardView(thumbnail: model.currentThumbnail)
                        .offset(dragOffset)
                        .rotationEffect(.degrees(Double(dragOffset.width / 20)))
                        .gesture(swipeGesture)
                        .padding(.horizontal, 24)

                case .finished:
                    finishedSummary
                }
            }
            .frame(maxWidth: .infinity, maxHeight: .infinity)

            controls
        }
        .padding(.vertical, 24)
        .task { await model.start() }
    }

    // MARK: - Subviews

    private var header: some View {
        HStack {
            Text("SwipeSort")
                .font(.title2.bold())
            Spacer()
            if model.phase == .ready {
                Text("\(model.currentIndex + 1) / \(model.totalCount)")
                    .font(.subheadline)
                    .foregroundStyle(.secondary)
            }
        }
        .padding(.horizontal, 24)
    }

    private var permissionDenied: some View {
        VStack(spacing: 12) {
            Image(systemName: "photo.on.rectangle.angled")
                .font(.system(size: 48))
                .foregroundStyle(.secondary)
            Text("Photo library access is required.")
                .font(.headline)
            Text("Grant full access in Settings → SwipeSort → Photos.")
                .font(.subheadline)
                .foregroundStyle(.secondary)
                .multilineTextAlignment(.center)
                .padding(.horizontal, 32)
        }
    }

    private var finishedSummary: some View {
        VStack(spacing: 12) {
            Image(systemName: "checkmark.circle.fill")
                .font(.system(size: 56))
                .foregroundStyle(.green)
            Text("Session complete")
                .font(.title2.bold())
            Text("\(model.queue.keepCount) kept · \(model.queue.deleteCount) marked for delete")
                .foregroundStyle(.secondary)
            Text("Deletion arrives in v0.2. Nothing was removed.")
                .font(.footnote)
                .foregroundStyle(.tertiary)
                .multilineTextAlignment(.center)
                .padding(.horizontal, 32)
        }
    }

    private var controls: some View {
        HStack(spacing: 24) {
            Button(action: { Task { await model.swipeDelete() } }) {
                Label("Delete", systemImage: "trash")
                    .frame(maxWidth: .infinity)
            }
            .buttonStyle(.borderedProminent)
            .tint(.red)
            .disabled(model.phase != .ready)

            Button(action: { Task { await model.undo() } }) {
                Label("Undo", systemImage: "arrow.uturn.backward")
            }
            .buttonStyle(.bordered)
            .disabled(model.queue.decisions.isEmpty)

            Button(action: { Task { await model.swipeKeep() } }) {
                Label("Keep", systemImage: "checkmark")
                    .frame(maxWidth: .infinity)
            }
            .buttonStyle(.borderedProminent)
            .tint(.green)
            .disabled(model.phase != .ready)
        }
        .padding(.horizontal, 24)
    }

    // MARK: - Gesture

    private var swipeGesture: some Gesture {
        DragGesture()
            .onChanged { value in
                dragOffset = value.translation
            }
            .onEnded { value in
                let translation = value.translation.width
                // Default direction per vision doc: right = delete, left = keep.
                // v0.7 makes this configurable via AppSettings.deleteSwipeDirection —
                // route through model.swipe(_:using:) once that's introduced.
                if translation > horizontalThreshold {
                    withAnimation(.easeOut(duration: 0.2)) {
                        dragOffset = CGSize(width: 600, height: 0)
                    }
                    Task {
                        await model.swipeDelete()
                        dragOffset = .zero
                    }
                } else if translation < -horizontalThreshold {
                    withAnimation(.easeOut(duration: 0.2)) {
                        dragOffset = CGSize(width: -600, height: 0)
                    }
                    Task {
                        await model.swipeKeep()
                        dragOffset = .zero
                    }
                } else {
                    withAnimation(.spring()) {
                        dragOffset = .zero
                    }
                }
            }
    }
}
```
