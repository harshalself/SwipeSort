# SwipeSort v0.3 — Persistence & Resume Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Prerequisite:** v0.2 tagged and trusted. `commitDecisions` works end-to-end. `ReviewedAssetRecord` schema exists but is unused.

**Goal:** Never re-swipe an asset the user already reviewed. Persist decisions to SwiftData on every swipe. On launch, skip previously reviewed assets so the swipe deck resumes at the first unreviewed photo. Show per-month progress.

**Architecture:** A `ReviewedAssetStore` wraps the SwiftData `ModelContext`. `SwipeSessionModel` gains a filter step in `loadInitial()` that walks the `PHFetchResult` and skips indices whose `localIdentifier` is in the store. A `ProgressBadgeView` renders "X of Y reviewed" per month grouping in a new landing screen.

**Tech Stack:** SwiftData `@Model`, `ModelContainer`, `FetchDescriptor`. All existing.

**Signatures after this version:**
- `SwipeSessionModel.init(library:, store: ReviewedAssetStore? = nil, targetSize:)`
- `SwipeStackView.init(library:, store: ReviewedAssetStore)`

## Global Constraints

- All v0.1/v0.2 constraints apply.
- The `PHFetchResult` cursor is still the source of truth for what exists. The store is a **filter overlay**, never a mirror.
- On launch, filtering must be O(reviewed count), not O(library count) — use a `Set<String>` in memory.
- Deleting an asset (v0.2 commit path) must also write a `ReviewedAssetRecord` so retries don't re-surface it.
- No blocking of first launch on the whole library — index reviewed IDs into memory on `.task { }` of the landing view.

## Research References

- `PHFetchResult` lazy semantics: `docs/RESEARCH.md` §4.1 (iterate via `object(at:)`, never materialize).
- First-launch indexing: §4.5 (background `OperationQueue` at `.utility` if heavy work needed; here we only build a `Set<String>` so main-thread is fine).

```swift
import Foundation
import SwiftData

@MainActor
final class ReviewedAssetStore {

    private let context: ModelContext

    init(context: ModelContext) {
        self.context = context
    }

    func markReviewed(_ identifier: AssetIdentifier, as decision: ReviewedDecision) throws {
        // Upsert: replace decision if the identifier already exists.
        let raw = identifier.rawValue
        let descriptor = FetchDescriptor<ReviewedAssetRecord>(
            predicate: #Predicate { $0.assetLocalIdentifier == raw }
        )
        if let existing = try context.fetch(descriptor).first {
            existing.decisionRawValue = decision.rawValue
            existing.reviewedAt = .now
        } else {
            let record = ReviewedAssetRecord(
                assetLocalIdentifier: raw,
                decisionRawValue: decision.rawValue
            )
            context.insert(record)
        }
        try context.save()
    }

    func removeReviewed(_ identifier: AssetIdentifier) throws {
        let raw = identifier.rawValue
        let descriptor = FetchDescriptor<ReviewedAssetRecord>(
            predicate: #Predicate { $0.assetLocalIdentifier == raw }
        )
        for record in try context.fetch(descriptor) {
            context.delete(record)
        }
        try context.save()
    }

    func reviewedIdentifiers() throws -> Set<String> {
        let descriptor = FetchDescriptor<ReviewedAssetRecord>()
        let records = try context.fetch(descriptor)
        return Set(records.map(\.assetLocalIdentifier))
    }

    func reset() throws {
        try context.delete(model: ReviewedAssetRecord.self)
        try context.save()
    }
}
```

Replace `loadInitial()`:

```swift
private func loadInitial() async {
    phase = .loading
    totalCount = await library.assetCount()

    // Snapshot reviewed set once per session.
    if let store {
        reviewedSet = (try? store.reviewedIdentifiers()) ?? []
    } else {
        reviewedSet = []
    }

    currentIndex = await firstUnreviewedIndex(from: 0)
    if currentIndex >= totalCount {
        phase = .finished
        currentThumbnail = nil
        return
    }
    await loadCurrent()
    phase = .ready
}

private func firstUnreviewedIndex(from start: Int) async -> Int {
    var i = start
    while i < totalCount {
        if let id = await library.assetIdentifier(at: i),
           !reviewedSet.contains(id.rawValue) {
            return i
        }
        i += 1
    }
    return totalCount
}
```

Update `swipeKeep()` / `swipeDelete()` to persist:

```swift
func swipeKeep() async {
    guard let thumb = currentThumbnail else { return }
    queue.record(.keep(thumb.identifier))
    reviewedSet.insert(thumb.identifier.rawValue)
    try? store?.markReviewed(thumb.identifier, as: .kept)
    await advance()
}

func swipeDelete() async {
    guard let thumb = currentThumbnail else { return }
    queue.record(.delete(thumb.identifier))
    reviewedSet.insert(thumb.identifier.rawValue)
    try? store?.markReviewed(thumb.identifier, as: .deleted)
    await advance()
}
```

Update `undo()` to also unmark from persistence:

```swift
func undo() async {
    guard let popped = queue.undoLast() else { return }
    reviewedSet.remove(popped.identifier.rawValue)
    // Best-effort remove from store; if the throw fires, in-memory set is
    // still authoritative for this session.
    try? store?.removeReviewed(popped.identifier)
    currentIndex = max(0, currentIndex - 1)
    phase = .ready
    await loadCurrent()
}
```

```swift
import Foundation

struct MonthKey: Hashable, Sendable, Comparable {
    let year: Int
    let month: Int

    var label: String {
        let comps = DateComponents(year: year, month: month)
        let date = Calendar.current.date(from: comps) ?? Date()
        let f = DateFormatter()
        f.dateFormat = "LLLL yyyy"
        return f.string(from: date)
    }

    static func < (lhs: MonthKey, rhs: MonthKey) -> Bool {
        if lhs.year != rhs.year { return lhs.year > rhs.year }  // newest first
        return lhs.month > rhs.month
    }
}
```

- [ ] **Step 3: Real impl in `PhotoKitLibrary`**

```swift
func monthlyBuckets() async -> [(MonthKey, [AssetIdentifier])] {
    let result = await ensureFetchResult()
    var buckets: [MonthKey: [AssetIdentifier]] = [:]
    let cal = Calendar.current
    result.enumerateObjects { asset, _, _ in
        guard let date = asset.creationDate else { return }
        let comps = cal.dateComponents([.year, .month], from: date)
        guard let y = comps.year, let m = comps.month else { return }
        let key = MonthKey(year: y, month: m)
        buckets[key, default: []].append(AssetIdentifier(asset.localIdentifier))
    }
    return buckets.keys.sorted().map { ($0, buckets[$0]!) }
}
```
