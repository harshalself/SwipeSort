# SwipeSort v0.6 — Power Filters Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Prerequisite:** v0.5 tagged. Media polish done.

**Goal:** Turn the "sort everything" firehose into a controllable stream. Add filters: date range, media type (photo/video/live), size (biggest first). Add a bulk-delete-all-in-filter action for extreme cleanup ("wipe all screenshots from 2019"). Filters apply to the `PHFetchResult` at load time and inform the LandingView entry-points.

**Architecture:** New `SwipeFilter` value type. `PhotoLibraryProviding.assetCount()` / `assetIdentifier(at:)` split into filtered variants; the underlying `PHFetchResult` is regenerated on filter change. LandingView gains a filter chooser sheet. A "Bulk Delete" screen shows the count matched by the current filter and offers one-shot batch delete.

**Tech Stack:** Same. Heavier use of `NSPredicate` on `PHFetchOptions`.

**Signatures after this version:**
- `SwipeStackView.init(library:, store: ReviewedAssetStore, filter: SwipeFilter)`
- `PhotoLibraryProviding.applyFilter(_:)` is new — filter is a load-time property; call before `SwipeSessionModel.start()`.

## Global Constraints

- All prior constraints apply.
- **Filter is a load-time property, not a per-swipe property.** Changing the filter kills the current session (with confirmation).
- Bulk delete still respects `DryRunMode` — the button says "Log" in dry-run, "Delete" when armed.
- Every filter combo must be expressible in a single `NSPredicate` — no post-fetch filtering, since that would materialize the whole cursor.

## Research References

- `PHFetchOptions.predicate` supports `creationDate`, `mediaType`, `mediaSubtypes` bitmask, `pixelWidth`, `pixelHeight`. `docs/RESEARCH.md` §4.1 (lazy cursor).
- Bursts are separate assets sharing `burstIdentifier` — filter with `includeAllBurstAssets = true` when we want the whole burst: `docs/RESEARCH.md` §2.4.

```swift
import Foundation
import Photos

/// Value type describing a subset of the photo library plus a sort order.
/// Conforms to `Hashable` so SwiftUI's `.task(id:)` and `Picker.tag(_:)`
/// see filter changes and rebuild dependent state.
struct SwipeFilter: Sendable, Hashable {

    enum MediaTypeFilter: Sendable, Hashable {
        case any
        case photosOnly
        case videosOnly
        case livePhotosOnly
        case screenshotsOnly
    }

    enum SortOrder: Sendable, Hashable {
        case newestFirst
        case oldestFirst
        case largestFirst
    }

    var mediaType: MediaTypeFilter = .any
    var dateRange: ClosedRange<Date>? = nil
    var minimumPixelDimension: Int? = nil
    var sortOrder: SortOrder = .newestFirst

    static let unfiltered = SwipeFilter()

    func nsPredicate() -> NSPredicate? {
        var parts: [NSPredicate] = []

        switch mediaType {
        case .any:
            break
        case .photosOnly:
            parts.append(NSPredicate(format: "mediaType == %d", PHAssetMediaType.image.rawValue))
        case .videosOnly:
            parts.append(NSPredicate(format: "mediaType == %d", PHAssetMediaType.video.rawValue))
        case .livePhotosOnly:
            parts.append(NSPredicate(format: "(mediaSubtypes & %d) != 0",
                                     PHAssetMediaSubtype.photoLive.rawValue))
        case .screenshotsOnly:
            parts.append(NSPredicate(format: "(mediaSubtypes & %d) != 0",
                                     PHAssetMediaSubtype.photoScreenshot.rawValue))
        }

        if let range = dateRange {
            parts.append(NSPredicate(format: "creationDate >= %@ AND creationDate <= %@",
                                     range.lowerBound as NSDate,
                                     range.upperBound as NSDate))
        }

        if let min = minimumPixelDimension {
            parts.append(NSPredicate(format: "pixelWidth >= %d OR pixelHeight >= %d", min, min))
        }

        guard !parts.isEmpty else { return nil }
        return NSCompoundPredicate(andPredicateWithSubpredicates: parts)
    }

    func nsSortDescriptors() -> [NSSortDescriptor] {
        switch sortOrder {
        case .newestFirst:
            return [NSSortDescriptor(key: "creationDate", ascending: false)]
        case .oldestFirst:
            return [NSSortDescriptor(key: "creationDate", ascending: true)]
        case .largestFirst:
            return [
                NSSortDescriptor(key: "pixelWidth", ascending: false),
                NSSortDescriptor(key: "pixelHeight", ascending: false),
            ]
        }
    }

    var summary: String {
        var parts: [String] = []
        switch mediaType {
        case .any: break
        case .photosOnly: parts.append("Photos")
        case .videosOnly: parts.append("Videos")
        case .livePhotosOnly: parts.append("Live Photos")
        case .screenshotsOnly: parts.append("Screenshots")
        }
        if let range = dateRange {
            let f = DateFormatter()
            f.dateFormat = "yyyy"
            parts.append("\(f.string(from: range.lowerBound))–\(f.string(from: range.upperBound))")
        }
        if let min = minimumPixelDimension {
            parts.append("≥\(min)px")
        }
        return parts.isEmpty ? "All" : parts.joined(separator: " · ")
    }
}
```

private var activeFilter: SwipeFilter = .unfiltered

func applyFilter(_ filter: SwipeFilter) async {
    guard filter != activeFilter else { return }
    activeFilter = filter
    fetchResult = nil  // force rebuild on next access
    imageManager.stopCachingImagesForAllAssets()
}

private func ensureFetchResult() async -> PHFetchResult<PHAsset> {
    if let existing = fetchResult { return existing }
    let options = PHFetchOptions()
    options.sortDescriptors = activeFilter.nsSortDescriptors()
    if let predicate = activeFilter.nsPredicate() {
        options.predicate = predicate
    }
    let result = PHAsset.fetchAssets(with: options)
    fetchResult = result
    return result
}
```

import SwiftUI

struct FilterSheet: View {
    @Binding var filter: SwipeFilter
    @Environment(\.dismiss) private var dismiss

    var body: some View {
        NavigationStack {
            Form {
                Section("Media type") {
                    Picker("Type", selection: $filter.mediaType) {
                        Text("All").tag(SwipeFilter.MediaTypeFilter.any)
                        Text("Photos").tag(SwipeFilter.MediaTypeFilter.photosOnly)
                        Text("Videos").tag(SwipeFilter.MediaTypeFilter.videosOnly)
                        Text("Live Photos").tag(SwipeFilter.MediaTypeFilter.livePhotosOnly)
                        Text("Screenshots").tag(SwipeFilter.MediaTypeFilter.screenshotsOnly)
                    }
                }

                Section("Sort") {
                    Picker("Order", selection: $filter.sortOrder) {
                        Text("Newest first").tag(SwipeFilter.SortOrder.newestFirst)
                        Text("Oldest first").tag(SwipeFilter.SortOrder.oldestFirst)
                        Text("Largest first").tag(SwipeFilter.SortOrder.largestFirst)
                    }
                }

                Section("Date range") {
                    DateRangePicker(range: $filter.dateRange)
                }
            }
            .navigationTitle("Filter")
            .toolbar {
                ToolbarItem(placement: .cancellationAction) {
                    Button("Reset") { filter = .unfiltered }
                }
                ToolbarItem(placement: .confirmationAction) {
                    Button("Done") { dismiss() }
                }
            }
        }
    }
}

private struct DateRangePicker: View {
    @Binding var range: ClosedRange<Date>?
    @State private var enabled = false
    @State private var start: Date = Calendar.current.date(byAdding: .year, value: -1, to: Date()) ?? Date()
    @State private var end: Date = Date()

    // Computed bindings write the outer `range` on any pick, so we don't
    // need three separate `.onChange` observers racing each other.
    private var startBinding: Binding<Date> {
        Binding(get: { start }, set: { start = $0; syncRange() })
    }
    private var endBinding: Binding<Date> {
        Binding(get: { end }, set: { end = $0; syncRange() })
    }
    private var enabledBinding: Binding<Bool> {
        Binding(get: { enabled }, set: { enabled = $0; syncRange() })
    }

    private func syncRange() {
        // Guard against inverted ranges (end < start) — clamp to a single day.
        let low = min(start, end)
        let high = max(start, end)
        range = enabled ? (low...high) : nil
    }

    var body: some View {
        Toggle("Enable", isOn: enabledBinding)
        if enabled {
            DatePicker("From", selection: startBinding, displayedComponents: .date)
            DatePicker("To", selection: endBinding, displayedComponents: .date)
        }
    }
}

@MainActor
final class BulkDeleteHelper {
    private let library: PhotoLibraryProviding
    init(library: PhotoLibraryProviding) { self.library = library }

    func matchedCount() async -> Int { await library.assetCount() }

    func deleteAll() async -> CommitResult {
        let n = await library.assetCount()
        guard n > 0 else { return .success(affectedCount: 0) }
        let ids = await library.identifiers(in: 0..<n)
        return await library.commitDeletions(ids)
    }
}

import SwiftUI

struct BulkDeleteView: View {
    let library: PhotoLibraryProviding
    @State private var filter: SwipeFilter = .unfiltered
    @State private var matched: Int = 0
    @State private var result: CommitResult?
    @State private var confirming = false

    var body: some View {
        VStack(spacing: 24) {
            Text("Bulk delete")
                .font(.title.bold())

            NavigationLink("Filter: \(filter.summary)") {
                FilterSheet(filter: $filter)
            }
            .buttonStyle(.bordered)

            Text("\(matched) asset(s) match")
                .font(.title2)

            if DryRunMode.isEnabled {
                Label("Dry-run ON — nothing will actually delete", systemImage: "shield.lefthalf.filled")
                    .foregroundStyle(.orange)
            }

            Button(role: .destructive) {
                confirming = true
            } label: {
                Label(DryRunMode.isEnabled ? "Log deletion" : "Delete all matched", systemImage: "trash")
                    .frame(maxWidth: .infinity)
            }
            .buttonStyle(.borderedProminent)
            .tint(.red)
            .disabled(matched == 0)

            if let result {
                Text(String(describing: result)).foregroundStyle(.secondary)
            }
        }
        .padding()
        .task(id: filter) {
            await library.applyFilter(filter)
            matched = await library.assetCount()
        }
        .confirmationDialog("Delete \(matched) asset(s)?", isPresented: $confirming, titleVisibility: .visible) {
            Button("Delete", role: .destructive) {
                Task {
                    let helper = BulkDeleteHelper(library: library)
                    result = await helper.deleteAll()
                    matched = await library.assetCount()
                }
            }
        }
    }
}
```
